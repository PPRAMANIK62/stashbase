Why staged dots, not a spinner

Preparation is a real staged Interface — discover → install → authenticate → configure — not an indeterminate wait. Making the stages visible is the one place this screen spends its design budget; everything else stays quiet.

One inherited palette

Every color here is the shipped neutral ladder plus the single #6B97FF focus/in-progress accent — no new brand color for a settings surface people already trust.
