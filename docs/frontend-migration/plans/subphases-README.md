# Implementation Subphases

These files divide the frontend reimplementation into small tracer-bullet
tasks. Task numbers are stable dependency identifiers, not dates. A task may
start when every listed blocker is complete and its affected capability-ledger
rows have been assessed.

- [Subphase 0 — Toolchain and Enforcement](subphases-0-toolchain-and-enforcement.md)
- [Subphase 1 — Design and Electron Shell](subphases-1-design-and-electron-shell.md)
- [Subphase 2 — Bootstrap and Workspace](subphases-2-bootstrap-and-workspace.md)
- [Subphase 3 — Documents](subphases-3-documents.md)
- [Subphase 4 — Retrieval and Preparation](subphases-4-retrieval-and-preparation.md)
- [Subphase 5 — Agent and Convergence](subphases-5-agent-and-convergence.md)
- [Subphase 6 — External, Reporting, and Recovery](subphases-6-external-reporting-and-recovery.md)
- [Subphase 7 — Journey Proof and Cutover](subphases-7-journey-proof-and-cutover.md)

Every task delivers focused evidence and updates its owning product and review
contracts in the same change. The task descriptions state outcomes rather than
fixed source paths so implementation ownership may deepen without making this
plan stale.
