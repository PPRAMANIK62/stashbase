# Establish an accessible shell, bounded forms, and semantic notifications

The replacement targets WCAG 2.2 AA and applies a non-secret appearance
snapshot before React mounts. React Hook Form with Zod resolvers handles
multi-field mechanics without owning application policy. One root Sonner
Toaster is hidden behind an app notification capability and uses headless
Tailwind/shadcn rendering; actionable recovery remains inline, persistent, or
modal according to scope. Persisted writes stay backward-readable, safely
ignorable, or explicitly migratable so a previous release can recover safely.
This favors accessible continuity and one complete replacement over generic
form, toast, dual-renderer, or microfrontend shortcuts.
