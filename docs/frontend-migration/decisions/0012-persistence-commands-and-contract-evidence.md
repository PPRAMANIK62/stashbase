# Make persistence, commands, and migration evidence explicit

Session persistence uses versioned concept-specific adapters rather than
whole-store middleware, and windows reconcile through durable owners rather
than renderer replication. App composition owns typed keyboard/menu commands.
Temporary replacement checks stay separate until the complete migration makes
them canonical; protocol operations prove Zod schemas plus mappings and
compatibility fixtures, and the capability ledger records behavior disposition,
decision, Interface, compatibility, exact evidence, and deletion conditions.
This adds explicit records and gates so convenience state, shortcuts, or broad
passing tests cannot hide architectural or behavioral drift.
