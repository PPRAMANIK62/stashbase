# User and Operator Guides

This directory contains task-oriented documentation for using or configuring a
shipping StashBase build. It is not a second home for product design,
maintainer contracts, or release checklists.

Current guides:

- [MCP Configuration](mcp-configuration.md) — client setup examples,
  Streamable HTTP, Docker access, credentials, and transport boundaries.

Add a guide here when a user or operator needs durable steps that would make
the external README too long. Product intent belongs in `design-docs/`;
implementation invariants belong in `code-review/`; residual release checks
belong in `release-checklists/`.
