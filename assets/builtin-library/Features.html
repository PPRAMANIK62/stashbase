What StashBase can do

The short version — open any capability for the detail.

01Work with local folders

Add an existing folder or create a new one. StashBase reads and updates the files in place, and you can remove a folder from the library without deleting it from disk.

02Read more than plain text

Open Markdown, HTML, JSON, PDF, DOCX, images, audio, and video. StashBase can extract PDF and DOCX text, run image OCR, and transcribe supported audio and video with a local model.

Good to know: prepared text stays in StashBase’s application data. Your original file remains the visible source.
03Search by word or meaning

Exact search works without setup across source text and any prepared text that is ready. AI Index adds meaning-based search across the whole library or one folder.

Good to know: sign in to StashBase for free monthly AI Index usage, or use your own OpenAI or OpenRouter key. Exact search needs neither.
04Work with Claude Code or Codex

Start a Chat with Claude Code or Codex and choose Library or a single folder as its scope. Attach or mention files when you want them included, and approve sensitive actions explicitly.

Good to know: StashBase uses a supported system runtime when available. If one is missing, installation starts only after you choose Install and continue.
05Connect other tools through MCP

StashBase gives compatible local clients bounded access to your authorized library through MCP. Built-in Claude Code and Codex setup is automatic; copy the configuration from Settings for other clients.

Good to know: keep StashBase running while an MCP client is using it.
06Keep source and support data separate

The Files sidebar shows your source files, not generated transcripts, OCR text, or index records. Those support files stay hidden and can be rebuilt from the source.

Ways to use it

Start with a folder you already have and a real question you want to answer.

  • Take a project from requirements to delivery Keep requirements, meeting notes, decisions, and implementation together so an Agent can retrieve constraints and record accepted outcomes.
  • Complete a course or research project Combine papers, slides, recordings, experiments, and notes; find supporting evidence and keep conclusions in an ordinary document.
  • Reuse a personal archive Make years of notes, PDFs, images, recordings, and earlier Agent output searchable without reorganizing the original folders.
  • Work with documents and project data together Read, search, and explicitly edit prose and JSON without moving either into a separate workspace.

Start by adding a folder. Enable AI Index, an Agent, or external MCP access only when you need it.
